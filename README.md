# AstraTerra — AI Agent Dev Team Demo

A demonstration of **building a full-stack application using an AI agent development team** in GitHub Copilot. The agents collaborate in a pipeline — from UX mockup to database scripts to API to React UI — producing a working interplanetary study abroad portal ("AstraTerra") for the fictional TerraFirma Polytechnic.

## What This Demonstrates

This repo shows how specialized AI agents can be chained together to build a complete application from a legacy mockup. The workflow:

1. **Start with a legacy mockup** (`docs/mockups/at-dashboard.html`) — a dated Bootstrap 3-era interface
2. **Generate a modern UX design** using the UX Designer agent
3. **Build the full stack** using the Dev Orchestrator agent, which delegates to Database → API → UI agents in sequence

The result is a working React + .NET + Azure SQL application with seed data, all generated by agents.

### Running the Agents with Claude

This demo uses **Claude agents in GitHub Copilot** (VS Code). The agent definitions in `.github/agents/` provide specialized modes, and the project instructions in `.github/instructions/` and `.github/copilot-instructions.md` give Claude the project context automatically.

#### Quick Start: Use the Pre-Built Plan

The fastest way to go from mockup to working app is to point Claude at [`build-with-claude.md`](build-with-claude.md) — a pre-built, phased plan that walks through UX mockup → database scripts → API layer → React UI in order:

```
Follow the plan in build-with-claude.md to build the full application
from the legacy mockup at docs/mockups/at-dashboard.html
```

Claude will execute each phase sequentially, delegating to the right sub-agent at each step.

#### Step-by-Step: Drive Each Phase Yourself

Alternatively, invoke the agents individually using the `@` mention syntax or by switching modes:

**Step 1 — Generate the modern mockup** (UX Designer agent):
```
@ux-designer build me a modern dashboard mockup based on the legacy
mockup at docs/mockups/at-dashboard.html
```

**Step 2 — Build the full stack** (Dev Orchestrator agent):
```
@dev-orchestrator create the application for the modern AT dashboard.
From the database scripts on up to the API and UI layers.
DB scripts should use run-sql-scripts.
```

In Dev Orchestrator mode, Claude reads the mockup, plans the phases (DB → API → UI), and delegates to the Database, API, and UI sub-agents automatically.

#### What `build-with-claude.md` Contains

The pre-built plan covers five phases:

| Phase | What it does |
|-------|-------------|
| **1. UX Mockup** | Generate a modern HTML/CSS mockup from the legacy UI |
| **2. Database Scripts** | Create idempotent DDL + seed data matching the mockup |
| **3. API Layer** | Build .NET controllers, services, DTOs with EF Core projections |
| **4. React UI** | Create page components, CSS, and API client wiring |
| **5. Restyle** | Refine the React UI to match the mockup's visual design |

Each phase includes the exact rules Claude should follow (e.g., "use CSS/SVG charts, no JS libraries", "use IF NOT EXISTS guards", "async/await with CancellationToken"). You can also run individual phases by referencing them directly.

## Scope

Interplanetary study abroad management workflows:

- **Dashboard** — enrollment overview, headcount by program track, portal alerts, travel holds
- **Traveler Search** — searchable, sortable traveler list with advanced filters
- **Traveler Record Detail** — tabbed view of demographics, program track, transit schedule, evaluations, holds
- **Program Track Application** — program search, apply, waitlist management
- **Transit History** — term-by-term transit history, cumulative progress

## Agent-Driven Development

This project uses seven specialized Copilot agents that chain together in a pipeline. Each agent has a focused role, reads specific inputs, and produces artifacts that downstream agents consume.

```

        ▼
   UX Designer ──────────► HTML mockups
        │
        ▼
  Domain Designer ────────► Design specs
        │
        ▼
  ┌─────────────────────────────────────┐

  │  plans & sequences the work         │
  │                                     │
  │  Database Dev ───► Entities, seeds  │
  │       │                             │
  │       ▼                             │
  │    API Dev ──────► Controllers      │
```

## Getting Started

### Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/)
- [Node.js](https://nodejs.org/) (LTS)
- [Azure CLI (`az`)](https://learn.microsoft.com/cli/azure/)
- [Azure Developer CLI (`azd`)](https://learn.microsoft.com/azure/developer/azure-developer-cli/)

### Configure SQL Admin

Set your Entra ID user as the SQL admin via `azd` environment variables:

```bash
# Get your object ID
az ad signed-in-user show --query "{displayName: displayName, id: id}" -o json

# Set in azd environment
azd env set SQL_ADMIN_DISPLAY_NAME "Your Name"
azd env set SQL_ADMIN_OBJECT_ID "your-object-id-guid"
```

### Run Locally

```bash
# API
cd src/api/AstraTerra.Api
dotnet run

# Frontend
cd src/web
npm install
npm run dev
```

### Seed the Database

After deploying infrastructure, run the SQL setup scripts:

```powershell
./scripts/run-sql-scripts.ps1
```

This discovers the SQL server from the `azd` environment, acquires an Entra ID token, and runs `001-create-tables.sql` and `002-seed-data.sql` in order.

### Deploy to Azure

```bash
azd up
```
