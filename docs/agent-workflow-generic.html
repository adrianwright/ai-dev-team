Step 1
UX
UX Designer
Produces static HTML/CSS mockups that stakeholders can review in a browser. Uses design system tokens to create page-level prototypes with realistic placeholder data.
Reads: legacy UI, use cases Creates: HTML mockups
mockups define fields & workflows
Step 2
DD
Domain Designer
Analyzes mockups and existing data to produce the single source of truth — structured specs with entity fields, relationships, access patterns, status workflows, and business rules. No code, only design documents.
Reads: mockups, existing data model Creates: domain design specs
design docs define entities & access patterns
🎯 Dev Orchestrator — plans & sequences the work
Phase 1
DB
Database Developer
Translates domain specs into data infrastructure. Selects appropriate data stores per entity, generates schema definitions, entity models, migrations, and seed data consistent with the mockup placeholders.
Reads: design specs, mockups Creates: entities, migrations, seed data
entities & mockups feed implementation
Phase 2
API
API Developer
Implements REST endpoints, service layers, and data access. Reads mockups for what the UI needs, design docs for business rules, and wires up the data access layer to the chosen data stores.
Reads: mockups, design specs, entities Creates: controllers, services, DTOs
endpoints ready for frontend
Phase 3
UI
UI Developer
Turns HTML mockups into production frontend components using design system tokens. Wires components to real API endpoints with loading, error, and empty states.
Reads: mockups, API endpoints Creates: frontend components, hooks
Orchestrator reads mockups, checks existing code, builds the plan, then delegates to each agent in sequence
reviews & hardens the full stack
Step 5
🔒
Security Developer
Configures authentication, security headers, secrets management, and network restrictions. Reviews the entire stack for vulnerabilities and scans uncommitted files for sensitive data before push.
Reads: API code, infra config, uncommitted files Creates: auth config, security hardening, pre-commit reviews
